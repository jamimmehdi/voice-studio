Voice

One pad, every voice.

Drop the dot anywhere. The shaded diagonal is the natural-sounding zone, where pitch and formant agree.

  • Pitch ±12 semitones, formant ±12 st, independent
  • Ten built-in voices + your own presets
  • Fast, Clean and Studio voice models

Clean

Silence between the words.

Noise removal learns your room and takes out fans, keyboards and hum. A live before / after reading shows exactly what it removes.

  • Light, Medium, Strong and a fine slider
  • About 10 ms of delay, no model download
  • Works together with the gate

Tone

Shape it by dragging the curve.

Six bands, each a draggable handle on the live spectrum. Scroll over a handle to change its Q, double-click to reset it.

  • Low shelf, four peaking bands, high shelf
  • De-esser with a split-band detector
  • Warmer-tone quick fix in one switch

Space

Radio, megaphone, cave.

Four characters and three amounts. Choose Walkie-talkie for your squad, Cave for a laugh, or just a touch of reverb to warm things up.

  • Radio, megaphone, walkie-talkie and cave
  • Reverb, echo and chorus sliders
  • Saved with your voice presets

Dynamics

Loud enough. Never harsh.

A soft-knee compressor with parallel mix evens out your level, and a look-ahead limiter makes sure nothing clips the game chat.

  • Gain-reduction meter on every dynamics stage
  • Gate with hold and release for clean pauses
  • Auto buffer keeps audio steady by itself

Tools

Built for how you actually play.

Soundboard & hotkeys

Your sounds, your keys.

Drop clips on the board and give each a key. Give every voice a global hotkey, too: jump to the cartoon voice for one joke, and a second press brings you back.

  • Clips play through your mic, so everyone hears them
  • Lowers your voice while a clip plays
  • Quick switch toggles with a single key

App profiles

The voice follows the game.

Add the programs you play and pick a voice for each. Voice Studio loads it when the game comes to the front and returns to your default when you leave.

  • Can start the engine for you
  • Only the program name is read, nothing is injected
  • One default voice for everything else

Voice library

Share a voice in one file.

Export any voice as a small .vsp file, import a friend’s, or pick from community voices. Record ten seconds to compare the raw you with the processed you.

  • Import and export, with strict validation
  • A/B test in your headphones, the game hears nothing
  • “Find my voice” measures your pitch and suggests settings

Phone remote

Change voice without leaving the match.

Overlays can’t draw over exclusive fullscreen games, so put the controls on your phone. Scan a QR code, and the same voices, sliders and sound pads are in your hand.

  • Works in every game mode, anti-cheat safe
  • Local network only, with a pairing code you can renew
  • Only controls travel, your voice never leaves the PC

Compact panel

Switch voices without leaving the match.

Close the main window and Voice Studio keeps running in the tray. Press Ctrl + Alt + V to bring up the compact panel over your game, change voice, then shrink it to a floating icon.

  • Never takes keyboard focus from the game
  • Works over borderless and windowed-fullscreen games
  • Shortcut is configurable in the app

Music player

  • Local files and playlist, or a pasted link

Game setup

Works with anything that has a microphone setting.

Voice Studio sends your processed voice into a virtual microphone. You pick that microphone in the game, once.

Your mic→Voice Studio→CABLE Input→CABLE Output→Game / Discord / OBS

Valorant

  1. In Voice Studio set Send to game / chat to CABLE Input and press Start engine.
  2. In Valorant open Settings → Audio → Voice Chat.
  3. Set Input Device to CABLE Output (VB-Audio Virtual Cable).
  4. Use the in-game voice test to confirm you hear the changed voice.

Anti-cheat: Voice Studio never injects into the game or touches its memory – it is just an audio device. The compact panel works in borderless or windowed fullscreen; for exclusive fullscreen use the phone remote.

Discord

  1. Open User Settings → Voice & Video.
  2. Set Input Device to CABLE Output (VB-Audio Virtual Cable).
  3. Turn Automatic Input Sensitivity on, and switch Discord’s Noise Suppression and Echo Cancellation off – Voice Studio already cleans the signal, and doubling up smears it.
  4. Optionally leave Automatic Gain Control off so your compressor stays in charge.

CS2, Apex Legends, Fortnite, Call of Duty and similar

  1. Start Voice Studio and pick CABLE Input as the output.
  2. Open the game’s Audio or Voice chat settings and look for Microphone / Voice input device.
  3. Choose CABLE Output (VB-Audio Virtual Cable).
  4. If the game has no device picker, use the Windows default method in the last tab – those games follow the system default recording device.

Tip: menu names differ between game versions. If you can’t find the option, search the settings for “microphone” or “voice”.

OBS, Streamlabs and streaming

  1. Add an Audio Input Capture source in OBS.
  2. Set Device to CABLE Output (VB-Audio Virtual Cable).
  3. Remove any other microphone from the mixer so you don’t transmit your real voice as well.
  4. To also put music and sounds on stream, keep the music dock and soundboard on – they travel through the same virtual mic.

Windows default, Microsoft Teams, Zoom, Google Meet

  1. Open Settings → System → Sound → Input (or the classic Sound control panel → Recording).
  2. Pick CABLE Output as the default input device.
  3. In Teams / Zoom / Meet choose the same device under audio settings, or leave it on “Default”.
  4. Switch the default back to your headset mic when you stop using Voice Studio.

FAQ

Good to know.

Will it get me banned in Valorant or other anti-cheat games?

Voice Studio is a normal Windows audio application. It does not inject code, read game memory or hook the game. App profiles only read the name of the program in front, the same way Task Manager does.

Why do I need VB-CABLE?

Games only accept real input devices. VB-CABLE is a free virtual device that carries the processed voice from Voice Studio into the game. Its licence doesn’t allow bundling it, so the app downloads it from vb-audio.com on request.

My teammates can’t hear me.

Open Tools → Why can’t they hear me?. It checks the engine, microphone, cable and output and can fix the common problems with one click. Restart the PC once after installing the driver.

The voice sounds robotic or choppy.

Choose the Clean or Studio voice model in the Engine card and keep Auto buffer on. Keep pitch changes within about ±6 semitones and use formant for the rest.

Is the noise removal an AI model?

No. It is a spectral noise suppressor that runs on your CPU in about 10 ms and needs no download. It learns your room continuously, so it also follows a fan that starts halfway through.

Is the phone remote safe?

It only answers devices on private network addresses, needs a random pairing code, accepts a short list of control messages and nothing else, and never carries audio. You can disconnect a phone or renew the code at any time.

I can’t see the panel over my game.

Overlays show over borderless and windowed-fullscreen games. Exclusive fullscreen hides all overlays; switch the game to borderless, or use the phone remote.

Windows says “unknown publisher”.

The installer isn’t code-signed yet. Choose More info → Run anyway. The source code is public on GitHub.

Does it collect any data?

No. Audio is processed on your PC and never sent anywhere. The only network calls are update checks, the community voice list and the optional VB-CABLE / link downloads you start yourself.

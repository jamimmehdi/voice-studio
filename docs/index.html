Voice

One pad, every voice.

Drop the dot anywhere. The shaded diagonal is the natural-sounding zone, where pitch and formant agree.

  • Pitch ±12 semitones, formant ±12 st, independent
  • Ten built-in voices + your own presets
  • Effect mix and a robot ring-modulator on top

Tone

Shape it by dragging the curve.

Six bands, each a draggable handle on the live spectrum. Scroll over a handle to change its Q, double-click to reset it.

  • Low shelf, four peaking bands, high shelf
  • De-esser with a split-band detector
  • Warmer-tone quick fix in one switch

Dynamics

Loud enough. Never harsh.

A soft-knee compressor with parallel mix evens out your level, and a look-ahead limiter makes sure nothing clips the game chat.

  • Gain-reduction meter on every dynamics stage
  • Gate with hold and release for clean pauses
  • Quick fixes for common problems, one tap each

Game setup

Works with anything that has a microphone setting.

Voice Studio sends your processed voice into a virtual microphone. You pick that microphone in the game, once.

Your mic→Voice Studio→CABLE Input→CABLE Output→Game / Discord / OBS

Valorant

  1. In Voice Studio set Send to game / chat to CABLE Input and press Start engine.
  2. In Valorant open Settings → Audio → Voice Chat.
  3. Set Input Device to CABLE Output (VB-Audio Virtual Cable).
  4. Use the in-game voice test to confirm you hear the changed voice.

Anti-cheat: Voice Studio never injects into the game or touches its memory – it is just an audio device. Overlay panel works in borderless or windowed fullscreen; exclusive fullscreen hides every overlay.

Discord

  1. Open User Settings → Voice & Video.
  2. Set Input Device to CABLE Output (VB-Audio Virtual Cable).
  3. Turn Automatic Input Sensitivity on, and switch Discord’s Noise Suppression and Echo Cancellation off – Voice Studio already cleans the signal, and doubling up smears it.
  4. Optionally leave Automatic Gain Control off so your compressor stays in charge.

CS2, Apex Legends, Fortnite, Call of Duty and similar

  1. Start Voice Studio and pick CABLE Input as the output.
  2. Open the game’s Audio or Voice chat settings and look for Microphone / Voice input device.
  3. Choose CABLE Output (VB-Audio Virtual Cable).
  4. If the game has no device picker, use the Windows default method in the last tab – those games follow the system default recording device.

Tip: menu names differ between game versions. If you can’t find the option, search the settings for “microphone” or “voice”.

OBS, Streamlabs and streaming

  1. Add an Audio Input Capture source in OBS.
  2. Set Device to CABLE Output (VB-Audio Virtual Cable).
  3. Remove any other microphone from the mixer so you don’t transmit your real voice as well.
  4. To also put music on stream, keep the music dock on – it travels through the same virtual mic.

Windows default, Microsoft Teams, Zoom, Google Meet

  1. Open Settings → System → Sound → Input (or the classic Sound control panel → Recording).
  2. Pick CABLE Output as the default input device.
  3. In Teams / Zoom / Meet choose the same device under audio settings, or leave it on “Default”.
  4. Switch the default back to your headset mic when you stop using Voice Studio.

FAQ

Good to know.

Will it get me banned in Valorant or other anti-cheat games?

Voice Studio is a normal Windows audio application. It does not inject code, read game memory or hook the game. The game just sees another microphone.

Why do I need VB-CABLE?

Games only accept real input devices. VB-CABLE is a free virtual device that carries the processed voice from Voice Studio into the game. Its licence doesn’t allow bundling it, so the app downloads it from vb-audio.com on request.

My teammates can’t hear me.

Check that the app’s output is CABLE Input, the engine is running (LIVE pill), and the game’s input device is CABLE Output. Restart the PC once after installing the driver.

The voice sounds robotic or choppy.

Switch Quality to Clean, raise the audio buffer setting, and keep pitch changes within about ±6 semitones – pair larger shifts with formant.

I can’t see the panel over my game.

Overlays show over borderless and windowed-fullscreen games. Exclusive fullscreen hides all overlays; switch the game to borderless.

Windows says “unknown publisher”.

The installer isn’t code-signed yet. Choose More info → Run anyway. The source code is public on GitHub.

Does it collect any data?

No. Audio is processed on your PC and never sent anywhere. The only network calls are update checks and the optional VB-CABLE / link downloads you start yourself.

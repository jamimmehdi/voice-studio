Using Voice Studio in a game

  1. Install a virtual audio cable. Windows cannot create a virtual microphone without a driver. If none is found, use the Install virtual microphone (VB-CABLE) button in the Input / Output panel, then reboot.
  2. In Voice Studio choose your real Microphone and set Output to CABLE Input (VB-Audio Virtual Cable).
  3. Click Start engine, pick a preset (e.g. Female – Natural) and talk.
  4. In the game / Discord / OBS select CABLE Output (VB-Audio Virtual Cable) as the input device.
  5. Turn on Monitor to hear yourself in headphones (use headphones to avoid feedback).

Tip: the lower the quality setting in the Voice module, the lower the delay. 1024 is the best balance for live talk. Disable “Windows noise suppression / auto-gain” unless you want them.

Install the virtual microphone

Games can only use real input devices, so Voice Studio needs a free virtual audio cable. This will download VB-CABLE from vb-audio.com (official source, about 1.3 MB), check its digital signature and start VB-Audio's own installer. Windows will ask for administrator permission.

  1. Click Download & start installer.
  2. In the VB-CABLE window click Install Driver.
  3. Restart your PC, then open Voice Studio again.

VB-CABLE is donationware by VB-Audio (vb-audio.com/Cable) – please consider supporting them. It is a separate product with its own licence.
